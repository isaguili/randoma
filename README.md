# Randoma

![Status](https://img.shields.io/badge/status-concluído-brightgreen)
![Rocketseat](https://img.shields.io/badge/Rocketseat-FullStack-8257E5)

Projeto desenvolvido durante a **Trilha FullStack da Rocketseat**, com o objetivo de criar uma aplicação capaz de gerar números aleatórios seguindo regras definidas pelo usuário. O foco foi exercitar **HTML, CSS e JavaScript**, aplicando conceitos de lógica de programação, validações e manipulação da DOM.

<img width="1370" height="702" alt="{144FEFD6-08FE-4D56-ADB1-4BF1F25BAEF4}" src="https://github.com/user-attachments/assets/f1e7cdcf-60d8-43f2-8899-d27269994cae" />

🔗 Acesse a aplicação: https://isaguili.github.io/randoma/

## Funcionalidades
- Geração de números aleatórios.
- Configuração de quantidade, valor mínimo e máximo.
- Opção para impedir números repetidos.
- Validação de entradas inválidas.
- Mensagens de erro intuitivas.
- Atualização dinâmica da interface sem recarregar a página.
- Animação na exibição dos números sorteados.

- Interpretação e implementação de requisitos funcionais.
- Manipulação da DOM utilizando JavaScript.
- Atualização dinâmica de elementos da interface.
- Criação de validações robustas para diferentes cenários.

## Como executar

Como este projeto utiliza apenas HTML, CSS e JavaScript, não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/isaguili/randoma.git
```

2. Acesse a pasta do projeto:

```bash
cd randoma
```
Execute o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no VS Code.
